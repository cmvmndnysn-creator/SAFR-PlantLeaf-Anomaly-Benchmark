# AppleLeaf9 processed subset

This directory contains the AppleLeaf9 subset used by the benchmark. It includes
four fixed healthy support partitions and a fixed test set with 80 healthy and
240 diseased images across eight disease categories. Five same-label healthy
image hashes are reused between shot settings; none overlaps the test set. This
is recorded in `../../metadata/AppleLeaf9/duplicate_groups.csv`.

Source, license, and citation information are provided in
`../../THIRD_PARTY_NOTICES.md`. Exact membership is recorded in
`../../metadata/AppleLeaf9/manifest.csv`.
