# PlantCity processed subset

This directory contains the selected eleven-crop PlantCity subset used by the
benchmark. Four mutually disjoint healthy support partitions are provided. The
fixed evaluation subset contains 2,278 healthy and 4,120 diseased images.

The directory label `Lokat` is preserved for compatibility with the processed
benchmark and refers to loquat.

Source, license, and citation information are provided in
`../../THIRD_PARTY_NOTICES.md`. Exact membership is recorded in
`../../metadata/PlantCity/manifest.csv`.
