# PlantVillage processed subset

This directory contains a selected nine-crop subset of the original RGB/color,
non-augmented PlantVillage images. It includes four mutually disjoint healthy
support partitions and a fixed test set containing healthy and diseased leaves.

Source, license, and citation information are provided in
`../../THIRD_PARTY_NOTICES.md`. Exact membership is recorded in
`../../metadata/PlantVillage/manifest.csv`.
